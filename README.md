# Hamid Riba Portfolio

Bilingual Unity and game-programming portfolio prepared for GitHub Pages.

## Publish on GitHub Pages

1. Upload the **contents** of this folder to the `HamidRiba` repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/(root)` folder, then press **Save**.
5. The site will be available at `https://hamid92010.github.io/HamidRiba/`.

## Main files

- `index.html`: portfolio home page.
- `project.html`: bilingual project detail template.
- `styles.css`: complete responsive design.
- `app.js`: translations, project data and process interactions.
- `assets/`: images, videos, process material and CV files.

No installation or build command is required.
